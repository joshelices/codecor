2. Datos que podemos tratar

A través de los formularios disponibles en este sitio web pueden recopilarse datos facilitados directamente por el usuario, como nombre, teléfono, dirección de correo electrónico, fecha preferente de visita y contenido del mensaje.

3. Finalidad del tratamiento

Los datos serán tratados para atender las solicitudes realizadas por los usuarios, gestionar solicitudes de información, responder consultas y, cuando corresponda, gestionar solicitudes de visita relacionadas con los inmuebles publicados en el sitio web.

4. Base jurídica

La base jurídica del tratamiento será, según corresponda, la aplicación de medidas precontractuales solicitadas por el interesado, la ejecución de una relación contractual, el cumplimiento de obligaciones legales o el consentimiento del usuario cuando este sea necesario.

5. Conservación de los datos

Los datos personales se conservarán durante el tiempo necesario para atender la solicitud y, posteriormente, durante los plazos necesarios para cumplir las obligaciones legales aplicables.

Cuando el tratamiento se base en el consentimiento, los datos podrán conservarse hasta que dicho consentimiento sea retirado, sin perjuicio de otros plazos legales aplicables.

6. Destinatarios

Los datos podrán ser tratados por proveedores de servicios tecnológicos necesarios para el funcionamiento de la web y la gestión de los formularios, siempre conforme a las garantías y condiciones exigibles.

Actualmente el formulario de solicitud de visita utiliza el servicio Formspree como proveedor tecnológico para gestionar el envío de formularios.

7. Derechos

El usuario puede ejercer, cuando proceda, sus derechos de acceso, rectificación, supresión, oposición, limitación del tratamiento y portabilidad de sus datos, así como retirar el consentimiento cuando el tratamiento se base en este.

Para ejercer estos derechos deberá dirigirse al responsable del tratamiento mediante los datos de contacto indicados en esta política.

Asimismo, el usuario tiene derecho a presentar una reclamación ante la Agencia Española de Protección de Datos si considera que el tratamiento de sus datos no se ajusta a la normativa aplicable.

8. Seguridad

El responsable adoptará las medidas técnicas y organizativas apropiadas para proteger los datos personales frente a pérdida, alteración, acceso no autorizado o tratamiento ilícito.

9. Actualizaciones

Esta Política de Privacidad podrá actualizarse cuando resulte necesario para adaptarla a cambios normativos, tecnológicos o en los servicios ofrecidos a través del sitio web.
